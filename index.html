BUAT TOKO BARU — WIZARD HUBUNGKAN SUPABASE

Slug hanya huruf kecil, angka, dan tanda -. Tidak boleh kosong, duplikat, atau memakai 'super-admin' / 'zho-pos'.

Hubungkan Supabase

Proyek toko sudah dibuat saat akun Supabase dibuat — tempel Project URL + Publishable key proyek itu di bawah ini.

Lihat di proyek Supabase → Settings → API → Project URL.

Settings → API Keys → Publishable key. Kunci ini publik — aman ditempel di sini.

Dashboard Supabase → klik avatar → Access Tokens → Generate new token, beri nama mis. "panel-super-admin", lalu salin tokennya. Token ini yang dipakai wizard untuk memasang skema, memverifikasi tabel, dan mengambil key.

GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token, scope repo, beri nama mis. "panel-super-admin", lalu salin. Dipakai wizard untuk membuat repo toko + deploy.

PENGGUNA ADMIN TOKO

Pengguna ini yang dipakai untuk login ke aplikasi toko baru. Dibuat otomatis oleh wizard lewat relay — kata sandi tidak pernah disimpan di mana pun.

Boleh diubah, mis. admin@tokorafi.local — email ini harus sama dengan email baris pengguna Admin di database (wizard yang menyesuaikannya).

Sandi tidak bisa dilihat lagi sesudah toko dibuat — catat di tempat aman bila perlu.

Token hanya di memori browser ini. Token ditempel di atas hanya dipakai selama wizard jalan — tidak disimpan di localStorage, file, atau repo, dan dihapus begitu wizard selesai, dibatalkan, atau Bos keluar. Jangan tempel token di kolom lain / chat.
